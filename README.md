🌟 Overview
A modern, responsive website for A.C.K St Peter's Gacharage Church located in Ruaka, Kiambu County, Kenya. The website serves as a digital hub for the church community, providing information about ministries, events, sermons, and ways to connect and contribute.

🎯 Mission
"Growing in Faith, Serving in Love"

🚀 Getting Started
Prerequisites
Modern web browser (Chrome, Firefox, Safari, Edge)

Internet connection for external resources

Installation
Clone or download the project files

Ensure all files are in the same directory:

index.html

styles.css

script.js

media/ folder with images

Open index.html in a web browser

🔧 Customization
Updating Content
Church Information: Edit contact details in the Contact section

Ministries: Update ministry information in the JavaScript ministryData object

Events: Modify event cards in the Events section

Images: Replace images in the media/ folder

Styling Changes
Modify CSS variables in :root for color scheme changes

Adjust spacing and sizes in respective CSS classes

Update fonts in the CSS import section

Form Integration
Update Formspree endpoints in form action attributes

Customize form fields as needed
